# Call-Centre-Analytics-Dashboard

## Project Overview
An Excel-based analytics project designed to evaluate call centre operations, monitor key performance indicators, and compare agent performance using an interactive dashboard.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Slicers and KPI reporting

## Key Performance Indicators
- Total calls
- Answered and dropped calls
- Call answer and drop rates
- Agent conversion rates
- Customer satisfaction
- Revenue performance

## Key Insights
- Analysed call performance across 20 agents and three communication channels: Phone, Chat, and Email.
- Identified an overall call answer rate of approximately 79.3% and a drop rate of 20.7%.
- Compared agent conversion performance to identify differences between top-performing agents and the overall average.

## Learning Outcomes
Practised data analysis, KPI calculation, interactive dashboard development, and operational performance reporting using Microsoft Excel.

## Project Type
Learning project completed using practice data.
