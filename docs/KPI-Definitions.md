# KPI Definitions — Call Centre Analytics

## Project Overview
This document explains the key performance indicators used to evaluate call centre operations in the Excel dashboard.

## 1. Total Calls
The total call volume represented by the dataset's call-count field.

## 2. Answered Calls
The number of calls successfully answered by agents.

## 3. Dropped Calls
The number of calls recorded as dropped or not answered, according to the dataset's definition.

## 4. Call Answer Rate
**Formula:** Answered Calls / Total Calls × 100

Measures the percentage of calls successfully answered.

## 5. Call Drop Rate
**Formula:** Dropped Calls / Total Calls × 100

Measures the percentage of calls dropped or not answered.

## 6. Agent Conversion Rate
Measures the percentage of eligible calls or leads that resulted in a conversion.

**Formula:** Conversions / Eligible Calls or Leads × 100

Use the denominator defined by your source dataset.

## 7. Customer Satisfaction
A satisfaction measure recorded in the dataset. Interpret its average using the scale defined by the source.

## 8. Revenue
The revenue recorded in the dataset for the selected reporting period or segment.

## Note
The definitions and calculations should match the actual fields, formulas, and metrics used in the Excel workbook.
