# Key Findings — Call Centre Analytics

## Project Summary
This project analyses call centre performance across 3,000 records, 20 agents, and three communication channels: Phone, Chat, and Email.

## Key Metrics
- Call answer rate: approximately 79.26%
- Call drop rate: approximately 20.74%
- Overall average agent conversion rate: approximately 26.53%
- Average conversion rate of the top four agents: approximately 28.03%

## Key Observations

### 1. Call Handling
The recorded answer rate was approximately 79.26%, while the drop rate was approximately 20.74%. The dropped-call rate provides an area for further investigation.

### 2. Agent Performance
The top four agents had an average conversion rate of approximately 28.03%, compared with an overall average agent conversion rate of approximately 26.53%.

### 3. Further Analysis
- Investigate which periods or channels have higher dropped-call rates.
- Compare agent performance across relevant KPIs.
- Explore how call volume and conversion rates vary by month and communication channel.

## Potential Business Actions
A call centre manager could investigate workload distribution, staffing requirements, and channel-level performance to understand the observed patterns.

These are suggested investigations, not proven causes of the results.

## Project Limitations
This is a learning project based on practice data. The findings describe the dataset and do not demonstrate actual operational improvements in a live call centre.
